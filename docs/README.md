# Documentation index

| Folder | Contents |
|---|---|
| [`projects/`](projects/) | Project write-up in short-paper form (question, data, method, results, limitations) |
| [`design/`](design/) | Design docs: purpose, interfaces, invariants, edge cases, test plan |
| [`decisions/`](decisions/) | Architecture & methodology decision records (ADRs), including rejected options |
| [`devlog/`](devlog/) | Dated session logs: what was done, bugs (symptom → cause → fix), next steps |
| [`learning/`](learning/) | Concept notes and derivations |
| [`interview/`](interview/) | Pitch, walkthrough, likely questions, things to be able to rebuild from scratch |

Conventions: docs are written in the same session as the code; dates match git history;
decisions are never edited after acceptance — they are superseded by a new ADR.
